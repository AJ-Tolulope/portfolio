HTML - Html Element

Course Info:

HTML Element:

Html elements define the look of a web page. All contents are displayed on the browser with the help of html elements. They communicate to the browser the type of markup we want to display.

Inside the html element/tag is where the content will be placed. And when I mean inside, html elements have an opening tag and a closing tag, and then the content goes in between. If you are wondering what the different between elements and tags is. Element is simply the content that is displayed on the web page, in an html file this elements are created by beginning with an <opening tag> and ending with a </closing tag>. For example:

<p> the paragraph content </p>

NOTE - Notice the forward slash - / - in closing tag. And also the letter "p" for paragraph is written in lowercase.

While some elements do not require a closing tag. You might have guessed why, and the reason is that, remember we said html is a text file. The html file can only contain text, so we can not directly import an image or a video into an html file.

NOTE - An element without a closing tag is called a self-closing element. An element inside another element is regarded as the child of that element.

The <html> element/tag is the container element which enclose all other element in an html document. There are two main element or children inside the <html> element.

  • Head tag

  • Body tag

Head Tag

The <head> tag enclose tags that are used to define informations about the website. The head tag is more like the brain of the website.

<head> i'm the head tag, and you? </head>

Inside the <head> tag, there are other tags like the meta tag, title tag and the link tag. These are the tags which are use to define the information about a website.

Meta Tag - A <meta> tag defines meta data about the website. The purpose of these tags is to interract with a browser or a search engine, giving more information about the website. The information can be from how the website should look like on screen, what the website content is about, the title of the website. Below are the most used meta tags in the head tag.

<meta charset="UTF-8">

The above <meta> tag tells the browser the character set (charset) used in the html file. It is important to specify the character set of of a web page so the browser will be able to interprete all the characters in a web page.

<meta name="description" content="This is my first website">

The <meta> tag above set the description of the website, describing the web page.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

The <meta> tag, as seen above, defines the viewport which set the width of our website relative to different screen the website is displayed on. Sounds confusing?, not to worry. More of meta tag on the advanced modules.

Title Tag - A <title> tag defines the title of the document. It is displayed on the title bar of a browser. once a website loads on the browser, the title will be display at the very top of the browser.

<title> Why webedit is awesome </title>

Link Tag - A <link> tag is used to link a given file to an html document. The file can either be an internal file or an external file. An internal file is a file within the website folder while an external file is from an outside source. The link tag has a main attribute called 'href', hypertext reference, which is used to define the location of the file that is to be linked to the document. Below is how a link tag looks like.

<link href="../../linklocation">

A you've seen below, the link tag is one of the tags that requires no closing tag.

Body Tag

The <body> tag is where all the website content goes. The <body> tag contains everything the users see and interract with on the browser. Which is sometimes refered as body content.

<body> i take in everything displayed on the browser </body>

The <body> element contains anything from the heading, paragraphs to more complicated layouts containing images, forms and tables. Most of what you will be learning throught the rest of the modules will be written between the opening <body> tag and closing </body> tag.

HTML - Basic Tags

Course Info:

Basic Html Tags:

There are a lot of html tags to talk about but you are going to learn the basic and the recent tags in html. We are focusing on the basic and the most used once because you are a beginner so we want to keep things as simple as posible. As you've known, html tags tells the web browser what to display and how to display it. For example, an heading and a paragraph are different so we use different tags for them. There are two types of html tag which are the content tag and the container tag. The content tag, as it sounds, are tags for different contents of the website. As said earlier we have tag for paragraphs, for images, etc.

Below are list of the most used content tags in an html document:

  • Heading tag

  • Paragraph tag

  • Image tag

  • Video tag

  • Anchor tag

heading tag - There are six types of heading tag which are use to display an heading on a web page. From 'h1' being the biggest heading to 'h6' which is the smallest heading.

<h1> i'm proud to be the biggest text in html </h1>

<h6> well i'm pretty good being the smallest </h6>

paragraph tag - This tag is used to display a paragraph on a web page

<p> there can be only one paragraph tag </p>

image tag - An image tag like a video tag also has "src" attribute which defines the location of the image.

<img src="../../imagelocation">

video tag - A video tag as you can tell helps display video on the browser. Like the anchor tag, video tag also has an attribute in it's opening tag called 'src' meaning source. The 'src' attribute tells the browser the location of the video we want to display. We also have other attributes like the 'autoplay' and 'controls', these tags does not require a value so they are placed in the opening tag

<video src="../../videolocation"></video>

NOTE - An attribute that does not have a value is called "boolean attribute"

anchor tag - In every web page we visit, we are sure to find a link because without one we won't be able to move/navigate from one page to another. What makes this possible is an anchor tag. An anchor tag basically direct a visitor from one page to another, anchoring the way the visitor moves from different pages. The anchor tag is sometimes called a link tag but we already have a tag with that name. The anchor tag has an attribute called 'href', inside the opening tag, meaning hypertext reference which holds a value that tell the browser where to link a user.

<a href="../../page"> anchor tag </a>

<a href="https://www.google.com"> Google's homepage </a>

Container Tags:

Container Tags - These are tags used to give a nice and clean structure to the webpage, basically. Html is the language that helps structure our web page, and to do that, we need to first identify different section of the web page. Container tag makes it easy for us to give our web page a nice layout. There are different types of container tag indicating different section of a webpage. There are quit a number of tags in html, but we will be focusing on the main tags and the reason you don't have to know them all is that they all serve the same purpose, to layout the webpage and make our code well organised and also readable.

Below are some tags that help with the structuring of a website.

  • Section tag

  • Header tag

  • Main tag

  • Article tag

  • Aside tag

  • Footer tag

  • Div (Divition) tag

  • Span tag

Here is how to properly make use of the container tags to give our web page a nice structure.

All the tags above are refered to as a block element except span tag. More on block element and inline element on the advanced modules.

span tag - A <span> tag is a tag similar to the paragraph and heading tag but different in the sense that it only covers the width of it's content, i.e the width of the span element is determined by the content inside the element. It is called an 'inline' tag - an inline tag is a tag that takes the width of it's content and set them inline with other element - unlike a <paragraph> tag or an <heading> tag, the <span> tag is used to place an element in the same line with another element, hence the name 'inline'.

<span> just a text </span>

HTML - Attribute

Course Info:

Html Attribute:

We've talked about some elements that have a default attribute in their opening tag. Some tags like the image tag having the 'src' attribute and the anchor tag having the 'href' attribute, these are attribute that are set by default to a specific tags. But we do have other attribute that will be used on almost every tag in the document. The most used attributes on any tag are mainly:

  • class attribute

  • id attribute

  • style attribute

Class Attribute - The class attribute is basically used to assign a class name to an element. Think of it as a school grouped into classes. once you call on a particular class, everyone in that class is called. A class attribute is used to call an element from a css file

<div class="class_name"> this is a container tag </div>

First the attribute name is set follow by the value which should always be in quote.

Id Attribute - The id attribute on the other hand also is used to assign a name to an element but unlike class attribute, an element can only be given an id value different from any other element which makes the element unique. A class name can be assign multiple times to different elements but an id name is only assigned specially to an element.

Style Attribute - The style attribute is an attribute used to style an element right from the tag. It is called an inline styling. Normally we use css to style html elements but you might find yourself in some situation where you need to do some inline styling. Although we don't use them always but they can come in handy sometimes.

The style attribute has a lot of properties which we will talk about when we get to the css part of the course.

<p style="background-color:red"> </p>

Above is a simple styling which gives the paragraph a background color of red.

Html List Tag

You can list out your items or menu in form of list. Most of the time, lists are used for structuring navigation portion of the web page. There are two main types of lists.

Unordered List - Above is an unordered list, hence the name "ul". The list elements as an "li" tag in it. An unordered list is a collection of related items that have no specific order.This list is created using the "ul" tag. An unordered list will list items using bullets. It comes with three types of bullets: square, discs, circles. The default displayed by most web browsers is the disc. You can set the type of the bullet by using the "type" attribute with the value: square, disc or circle.

Ordered List - An Ordered list is just like an unordered list, except that the items are numbered instead of bulleted. The ordered list is created by using "ol" tag.

HTML - Form

Html Form:

<form action="script" method="posting method"> </form>

A form tag is an html element used to recieve informaton about the user. Html form are found in almost all websites in the internet. Forms are important in a website. We all most have filled one or two forms in the internet. Might be a log in form or a sign up form or even during a survey. Forms are used to collect data about the web user.

Form tag has four main attribute:

  • name

  • action

  • method

  • target

Name - This attribute describes the name of the form

Action - This attribute takes in a script location which will process the data uploaded.

Method - This tells the method in which the data will be uploaded. It takes in two main values, GET and POST.

Target - The target attribute specifies the target page where the result will be displayed. It takes two main values, _blank and _self.

These are different types of form input which are used to recieve data from a visitor.

  • Text input

  • Gmail

  • Password

  • Button

  • Checkbox

  • Radio

  • File

  • Sunmit

  • Reset
